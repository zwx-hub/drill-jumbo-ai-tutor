> AI 赋能校园实训 · 智创美好未来

## 项目简介

本作品面向职业院校工程机械实训教学场景，以三臂凿岩台车（隧道施工核心钻孔设备）为对象，融合 **通义千问、DeepSeek、豆包、Kimi** 四款国产主流大模型，构建一个集 **3D 可视化仿真、操作台数字孪生、AI 实训导师、竞赛考核评分**于一体的智能实训系统。

学生可在虚拟环境中完成台车定位、钻臂操作、钻孔作业、收车全流程训练，AI 导师实时讲解结构原理、操作要领并纠错评分，替代昂贵的真机操作训练，降低实训成本与安全风险。

## 核心功能

### 1. 多模型 AI 实训导师
| 模型 | 角色定位 |
|------|----------|
| 通义千问 | 结构原理导师 — 讲解钻臂组成、机械结构、连接方式 |
| DeepSeek | 故障排查专家 — 分析液压系统、钻孔异常、设备故障 |
| 豆包 | 操作要领教练 — 实训口诀、操作规范、动作分解 |
| Kimi | 安全规范讲师 — 安全规程、应急处置、劳保要求 |

- 支持单模型提问与四模型对比回答
- 内置实训四要点：一心五点、一线两端、一高一低、一快一慢
- 点击 3D 部件自动关联 AI 讲解

### 2. 3D 结构认知
- 隧道掌子面场景中的三臂凿岩台车 3D 模型
- **整体/爆炸视图切换**，10 个核心部件可点击查看
- 部件信息：名称、功能、连接方式（胀销6处/螺栓2处）、传感器位置

### 3. 操作台数字孪生
- 按真实实训操作台还原：三臂操纵杆、五块压力表（回转/冲击/推进/气压/水压）
- 泵起/泵停、润滑、高冲/低冲、急停按钮
- 鼠标拖操纵杆实时联动 3D 钻臂姿态

### 4. 三种实训模式
| 模式 | 说明 |
|------|------|
| 📚 教学引导 | 6 步逐步带练，每步弹出知识点讲解 |
| 🔧 自由练习 | 学生自主操作，探索参数与姿态关系 |
| 📝 考核评分 | 对标中铁七局竞赛标准，100 分制自动评分 |

### 5. 竞赛考核评分（100分制）
完全对标 2024 年中铁七局隧道工竞赛评分细则：

| 考试项目 | 分值 |
|----------|------|
| 安全基本素养 | 5 分 |
| 设备操作及安全驾驶（作业准备） | 24 分 |
| 凿岩操作能力（标准凿岩） | 44 分 |
| 收车 | 12 分 |
| 问答（推进梁保养） | 15 分 |

计时评分：钻孔效率 10 分钟内满分、栈桥通过 2 分钟内满分、收车 2 分钟内满分；孔位精度偏离 1cm 内满分。

## 技术参数（中铁装备 DJ3G）

- 钻臂编号：沿掘进方向 1 号臂（左）、2 号臂（中）、3 号臂（右）
- 钻臂补偿 1600mm，推进补偿 1800mm
- 大臂俯仰 +65°/-30°，左右摆动 ±45°，推进翻转 ±180°
- 钻孔直径：周边眼 45~64mm，掏槽眼 76~127mm
- 推进力 20~23kN，冲击功率 27~31kW
